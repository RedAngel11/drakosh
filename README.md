# drakosh
Описание проекта: 
Кратко - это учебный проект по созданию робота Дракошки, который сможет эмоционально поддерживать студента, а также напоминать ему о дедлайнах.
Для того, чтобы считать проект успешно завершенным, нужно выполнить следующие задачи:
1. написать прошивку микроконтроллера, которая будет:
  а) управлять всеми компонентами электросхемы (серво, светодиоды, дисплеи, микрофон и динамик - для них точно нужна нейронка)
  б) реализовывать связь с телеграммом (+ написан тг-бот)
2. соединить электросхему и ничего не сжечь, отладить код на плате Esp32-S3-DevKitC-1
3. напечатать свою плату, припаять всё что можно припаять
4. снять мерки получившихся внутренних деталей, разработать модель робота с учетом внутреннего размещения деталей
5. фиксить баги

Список компонентов схемы (может дополняться)
U1, U2 — Аккумуляторные батареи 18650 3,7 В (Panasonic NCR18650B, по 3400 мА·ч)
U3 — Модуль для PowerBank (IP5306)
U4 — Микроконтроллер ESP32-S3-DevKitC-1
U5 — Цифровой MEMS-микрофон I2S (INMP441)
U6 — Аудиомодуль-усилитель I2S (MAX98357A)
SP1 — Динамик (4 Ом, 3 Вт)
U7, U8 — Круглые IPS-дисплеи (GC9A01)
L1 — Адресная светодиодная лента (WS2812B)
M1-M10 — Сервоприводы MG90S
U9 - PCA9685 чтобы управлять сервоприводами
